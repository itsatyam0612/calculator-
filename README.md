# ApexCalc — Next-Gen Web Calculator

A web-based scientific and standard calculator built with HTML, Vanilla CSS, and JavaScript.

## Features

- 🎨 **4 Modern Themes**:
  - **Dark Neon**: Glassmorphism with neon indigo/purple accents
  - **Cyberpunk**: Glow effects with hot pink & cyan
  - **Prism Light**: Crisp high-contrast frosted glass
  - **Sunset Gold**: Warm crimson and sunset amber
- 🧮 **Dual Mode**:
  - Standard mode (Arithmetic, %, Backspace, Memory)
  - Scientific mode (`sin`, `cos`, `tan`, inverses, `log`, `ln`, `√`, `xʸ`, `n!`, `π`, `e`, `|x|`)
- 📐 **Trigonometry Units**: DEG / RAD toggle
- 🔊 **Web Audio Feedback**: Tactile click audio synthesized dynamically in-browser
- 📜 **Calculation History**: Log of past evaluations with 1-click recall into display
- 💾 **Memory Functions**: `MC`, `MR`, `M+`, `M-`, `MS` with indicator
- ⌨️ **Keyboard Support**: Full numpad and keyboard binding integration
- 📋 **Copy to Clipboard**: Quick copy button with toast notification

## File Structure

- `index.html` - App structure & layout
- `styles.css` - Custom styling, glassmorphism, animations & color themes
- `script.js` - Logic, math engine, history, audio synthesis, and key handling

## Running locally

Simply open `index.html` in any web browser!
